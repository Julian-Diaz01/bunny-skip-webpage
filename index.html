How it works

One mechanism, run the same way on every supported platform.

  1. 01

    A rule matches

    Every skip button — Netflix's, Hulu's, Paramount+'s — is stored as a plain selector string, not hardcoded per-site JavaScript. When the page matches a saved rule, Bunny Skip finds the element.

  2. 02

    It clicks once

    The matched button gets exactly the click a viewer would give it — nothing more. No ads, paywalls, or DRM content are ever touched; the mechanism only ever reaches the button you picked.

  3. 03

    It stays live

    Edit a rule in the popup and chrome.storage.onChanged pushes the change straight into the running content script. A broken selector gets re-picked, not redeployed — no code change, no reload.

Read the privacy policy

No backend

There is no server to log into and nothing stored off your machine. The extension runs entirely inside your browser.

No telemetry

No analytics, no tracking pixels, no usage data sent anywhere. What the extension does on a page stays on that page.

No eval

Rules are matched as selector strings, never executed as code. A rule describes a button; it can't reach past it.

Never touches ads or DRM

The mechanism only ever reaches the skip button you picked — ads, paywalls, and DRM content are explicitly out of scope.
